Pada minggu 3 ini, saya menerapkan beberapa widget Flutter untuk membuat tampilan lirik lagu, yaitu:
1. Text untuk menampilkan judul, penyanyi, lirik, dan nama pembuat.
2. IconButton untuk tombol previous, pause, next, dan fast forward.
3. Image.asset untuk menampilkan gambar cover lagu.
4. Row untuk menempatkan gambar dan lirik secara berdampingan.
5. Column untuk menyusun nama penyanyi dan lirik ke bawah.
6. PageView untuk membagi lirik menjadi dua halaman.
7. Expanded untuk mengatur pembagian ruang gambar dan lirik.
8. Scaffold sebagai kerangka utama halaman aplikasi.
